# Image Compare

Connect images, image batches or videos and run the node. Connecting the last socket adds another. A single image batch lets you compare its first two images directly. With no connections the preview clears and the workflow continues.

Automatic mode is the default. Each region shows its input name near the edge, with the image number when comparing batch images. Two sources use a wipe. Four use a movable cross. Three or five or more use radial slices. Drag around the center to rotate the slices, or use the arrow keys for fine adjustments. The video timeline scrubs all visible videos together.

Under **Settings → ⚡MNeMiC Nodes → Image Compare**, enable **Split View** for A/B dropdowns that let you choose any source or batch image. **Reverse comparison order** is on by default, placing B on the left in a horizontal wipe. Turn it off to use input order. **Wipe direction** offers Horizontal, Vertical and Diagonal for two-source comparisons. The divider defaults to 1 px thick and 70% transparent.

**Show source labels** is on by default. Turn it off for an unobstructed preview.
