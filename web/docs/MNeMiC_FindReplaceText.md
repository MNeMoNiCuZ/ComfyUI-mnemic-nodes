# 🔄 Find / Replace Text

Replaces every literal match in a string. Three single-line inputs.

## Inputs

- **string**: Text to process.
- **find**: Case-sensitive text to match. Empty leaves the string unchanged.
- **replace**: Replacement text. Empty deletes matches.

## Outputs

- **string**: Text with every match replaced.

## Examples

Find `red`, replace with `blue`: `red cat, red hat` becomes `blue cat, blue hat`.
